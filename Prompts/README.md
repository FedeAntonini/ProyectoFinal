# Prompts

Prompts editables de los agentes.

Los programas cargan estos archivos al iniciar. Si queres cambiar el comportamiento conversacional de un agente, modifica el `.md` correspondiente y reinicia el proceso.

Ubicacion por defecto:

```txt
ProyectoFinal/Prompts
```

Tambien se puede cambiar con:

```txt
AGENTAI_PROMPTS_PATH=C:\ruta\a\Prompts
```
